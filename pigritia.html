Why open models here

  • Offline. Gemma runs through Ollama on your own hardware. No connection needed after the model is pulled.
  • Private. Group chats and fridge photos stay on this machine.
  • Free. No per-token bill. Set it up once, use it forever.
  • Swappable. Change the model in Setup. Any model Ollama can run works here.

First-time steps

  1. Pull a model: ollama pull gemma3
  2. Allow this page to talk to Ollama. Quit Ollama, then start it with the origin allowed:
    macOS/Linux: OLLAMA_ORIGINS="*" ollama serve
    Windows (PowerShell): $env:OLLAMA_ORIGINS="*"; ollama serve
  3. Open this file, press Save and check.
